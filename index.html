Each mode uses the same engine and a different set of tools. Choose one to see what it does.

Driver Mode

Stay alert on long drives. A siren sounds when yawns or eye closure last longer than your limits.

  • Test the siren before you drive
  • Set volume, limits and cooldown
  • Every alert is saved with a time

Yawn Shown live in Driver mode
Alert Sounds on a real warning

Study Mode

A consent-based group session on one screen. Each face gets a box: green for fine, red for a warning, gray when unsure.

  • Temporary track IDs, never names
  • Summary at the end of every session
  • Smiling or not never counts against anyone
Green box Shown live in Study mode
Red box Warning active
Gray box Unsure or face lost

Expression analysis

See which facial expression the model predicts and how sure it is. These are estimates of how a face looks, not of how someone feels.

  • Happy, sad, angry, neutral, surprised, fearful, disgusted
  • Adjustable confidence limit
